Completion-chase paper bot: it buys pump.fun coins as their real SOL reserve climbs through 30 SOL — the leg toward the 85 SOL completion — but only when the climb looks broad (several distinct buyers, no single wallet dominating, no one huge spike) and the coin is young. It banks half at +50%, trails the rest to +100%, and cuts every loss at -20%. Paper money only; nothing is traded for real.

## Run it

```sh
node main.ts
```
